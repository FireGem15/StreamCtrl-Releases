## Mobile

[Preview →](screenshot_pages/mobile_screenshots.md)

### Features
- Trigger Streamer.bot actions from your phone
- Fully customizable categories and buttons
- Color picker for categories
- Haptic feedback with adjustable intensity
- Drag to reorder categories
- Grid and list layout with landscape support
- Dark theme

### Requirements
- Android phone
- [Streamer.bot](https://streamer.bot) running on your PC
- Both devices on the same WiFi network

### Setup
1. Download and install the APK
2. Open the app and tap the settings icon
3. Go to Connection
4. Enter your PC's local IP address (find it with `ipconfig` in terminal)
5. Port is `8080` by default
6. Tap Save

## Desktop

[Preview →](screenshot_pages/desktop_screenshots.md)

### Features
- Trigger Streamer.bot actions from your PC
- Fully customizable categories and buttons
- Color picker for categories
- Drag categories to any position in a 3-slot grid
- Hide and show sidebar
- Undo support in edit mode
- Dark theme

### Requirements
- Windows 10 or later (64-bit)
- [Streamer.bot](https://streamer.bot) running on your PC

### Setup
1. Download and run the installer
2. Open the app and go to Settings in the sidebar
3. Enter your PC's local IP address (find it with `ipconfig` in terminal)
4. Port is `8080` by default
5. Click Save
