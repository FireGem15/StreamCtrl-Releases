# What's New in Stream Ctrl

## v1.4.1
### New
- Help text shown when a category has no buttons in edit mode
- Connection status now hidden in edit mode for a cleaner look

### Bug Fixes
- Fixed app crashing on reopen after landscape mode — previously required reinstall to fix
- Fixed auto reconnect getting stuck in an infinite disconnected loop — now reconnects automatically without needing to manually press save in connection settings
- Fixed category expanding not working correctly

## v1.4.0
### New
- Grid/list toggle — tap the grid icon in the header to switch layouts
- Landscape mode automatically shows categories side by side
- Buttons no longer require an icon — leave empty for text-only buttons
- Icon picker with searchable Material Icons and emoji

### Bug Fixes
- Fixed landscape grid not sizing correctly
- Fixed auto reconnect after screen lock

## v1.3.0
### New
- Cleaner UI with proper icons throughout

### Improvements
- Edit button moved to left side for easier reach
- Header now shows current page name instead of app name
- Settings page updated with better icons and formatting

### Bug Fixes
- Fixed connection showing connected when Streamer.bot was off
- Auto reconnect now works properly after drops

## v1.2.0
### Improvements
- Categories now remember collapse state in Home and Edit modes separately 
- Category and button names now automatically capitalize the first letter
- Toast notifications now appear at the top of the screen for better visibility
- Added automatic connection checks every 10 seconds
- Added automatic reconnection attempts every 15 seconds when disconnected

### Bug Fixes
- Fixed connection status incorrectly showing as connected when Streamer.bot was closed

## v1.1.1
### Bug Fixes
- Fixed icon size on launcher
- Fixed splash screen cropping

## v1.1.0
### Improvements
- Category names centered on Home screen
- Added "What's New" section in settings

### Bug Fixes
- Fixed category collapse state not saving
- Fixed new categories inheriting the previous category's name
- New categories now default to "New Category"
- New buttons now default to "New Button"
